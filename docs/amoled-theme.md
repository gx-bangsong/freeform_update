# AMOLED 主题

入口：主页 → 米窗设置 → 外观 → 应用主题。

- 默认跟随系统；也可固定为浅色或 AMOLED 纯黑。
- 选择后 Activity 自动重建，偏好在进程重启后保留。
- 夜间窗口背景、卡片、弹窗和系统栏使用纯黑，关闭 Material 高度叠色；卡片以细描边区分。
- 服务创建的应用选择面板及小窗控件在下次打开时读取主题。不重启正在运行的小窗；第三方应用内部界面不受本设置控制。

## 验证

编译使用 `.github/workflows/verify-apk.yml`，push 后自动执行 `assembleDebug`。
成功后在对应 Actions run 的 Artifacts 中下载 `freeform-debug-apk`。

真机回归清单（编译成功不代表这些项目已经验证）：

1. 系统浅色下选择 AMOLED：检查主页、设置、应用列表、排序页、对话框的黑底和文字可读性。
2. 退出并重新打开应用：主题应保留。
3. 选择跟随系统并切换系统深浅色：页面及系统栏图标应同步变化。
4. 选择浅色：系统深色时仍保持浅色，导航栏按钮应清晰可见。
5. 关闭并重新打开悬浮应用面板：检查手动主题、横竖屏、图标与文字。
6. 检查小窗启动、缩放、通知入口等原有功能没有回归。

## 双面板侧栏（ver17）

历史检查：拉取完整历史后，`09cab52` 是当前 `FloatingView.kt` 和悬浮布局的首次提交；
其中“全部应用”会先移除快捷栏，再打开独立网格。`f4f58f7` 补齐源码时未修改这个逻辑。
可获取的历史中未找到截图中双面板布局的对应源码，因此本次按截图重建，而非回退整个应用。

- 打开侧栏默认同时显示三列全部应用和单列快捷应用，两个列表可分别滚动。
- 左侧模式：快捷栏在左、网格在右；右侧模式镜像排列。
- 点击快捷栏的“全部应用”可收起/展开网格；编辑与长按排序保留。
- 两个面板共用一个 overlay，点击空白区域或返回键一起关闭，启动应用后也一起关闭。
- 面板使用独立 8dp 小圆角，不沿用主页的 36dp 大圆角；夜间纯黑配细灰边框。
- 横竖屏按可用屏幕尺寸限制高度，旋转/关闭时取消旧面板的异步加载。

安装后请验证：左右位置、深浅色切换、横竖屏、快速反复打开/关闭、分别滚动、
长名称截断、空快捷列表、点击启动应用、编辑及长按排序。
