找不到设备 / 无法连接？
  • 在独立浏览器标签打开本页，不要使用内嵌预览。WebUSB 需要 HTTPS 或本机 localhost。
  • 关闭其他 WebADB 页面。若电脑 ADB 占用接口，在电脑终端执行 adb kill-server（会中断其他 ADB 工具）。
  • Windows 可能需要安装设备厂商的 ADB / WinUSB 驱动；Linux 可能需要配置 udev 权限。macOS 通常无需额外驱动。
  • 解锁手机，确认 USB 调试的 RSA 指纹授权。授权密钥保存在当前浏览器站点存储中；用后可在手机撤销 USB 调试授权。
